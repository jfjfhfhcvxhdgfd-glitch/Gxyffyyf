# Yıldız Avcısı

Tek dokunuşla oynanabilen, hem masaüstü hem de telefon için hazırlanmış küçük bir Unity oyunu.

## Oynanış

Mavi gemiyi ekranın alt kısmında hareket ettirip sarı yıldızları topla. Kırmızı meteorlar puanını azaltır. 30 saniye sonunda en yüksek puanı yapmaya çalış.

- **Bilgisayar:** `A` / `D`, ok tuşları veya fare ile hareket et.
- **Telefon:** Parmağını ekranın alt yarısında sağa-sola sürükle.
- Oyun bittikten sonra **Tekrar Oyna** düğmesine dokun veya tıkla.

## Unity'de açma

1. Unity Hub'da **Add / Open** seçeneğine tıkla.
2. Bu klasörü (`Gxyffyyf`) seç.
3. Unity'nin projeyi içe aktarmasını bekle ve `Assets/Scenes/Main.unity` sahnesini aç.
4. Play düğmesine bas.

Proje, tüm şekilleri ve arayüzü çalışma anında oluşturur; haricî görsel, paket veya prefab gerekmez.
